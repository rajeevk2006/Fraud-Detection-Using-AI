# SentinelPay AI

SentinelPay AI is a Streamlit-based fraud detection dashboard for payment and transaction risk analysis. It combines a trained machine learning model with an Ollama-powered AI agent to assess whether a transaction is likely to be fraudulent, explain the result, and provide recommended actions.

## Overview

This project is designed for fintech and payment-risk teams to:

- evaluate transaction risk through a user-friendly dashboard
- score transactions using a trained fraud detection model
- classify outcomes as LOW, MEDIUM, or HIGH risk
- generate an AI explanation of the model output using Llama 3.2
- review transaction history and aggregate audit metrics

## Features

- Transaction risk evaluation form with payment, merchant, device, and account details
- ML fraud probability scoring based on model inference
- Risk categorization with business-friendly decision guidance
- AI-generated diagnosis powered by Ollama and Llama 3.2
- Session-level metrics and charting for audit/log review
- Dark-themed dashboard for operational visibility

## How It Works

1. A user enters transaction details in the Streamlit app.
2. The app preprocesses the row using the saved preprocessing pipeline.
3. The trained fraud model predicts a fraud probability.
4. The result is classified as LOW, MEDIUM, or HIGH risk.
5. The AI agent uses Ollama Llama 3.2 to explain the ML outcome and recommend actions.
6. The app stores session history and visualizes risk trends and audit logs.

## Installation

### Prerequisites

- Python 3.9+
- pip
- Ollama installed and running locally

### Setup

```bash
git clone https://github.com/ayushi537/SentinelPay-AI.git
cd SentinelPay-AI

python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
# source .venv/bin/activate

pip install -r requirements.txt
```

### Install Ollama Model

This project uses the `llama3.2` model for AI explanations.

```bash
ollama pull llama3.2
```

Ensure Ollama is running before launching the app.

## Run the App

```bash
streamlit run app.py
```

Then open the local Streamlit URL shown in the terminal, typically:

```text
http://localhost:8501
```

## Usage

1. Open the app in your browser.
2. Navigate to the "Evaluate Risk" page.
3. Enter the transaction details such as amount, merchant category, country, device info, and account status.
4. Click "Run Security Assessment".
5. Review the fraud probability, risk level, and recommended action.
6. Open the "Agent Report" tab to view the AI explanation generated by Ollama.
7. Use the "Metrics & Logs" tab to analyze previous evaluations and audit history.

## Model and Data Notes

The app relies on saved artifacts in the `model/` directory:

- `fraud_model.pkl` — trained fraud detection model
- `preprocessor.pkl` — preprocessing logic used before model inference

If these files are missing, the app will display an error indicating the ML engine is not available.

## Notes

- This is a demonstration-style risk analytics project and is intended for educational and prototype use.
- The AI layer is designed to explain the model result rather than replacing the model itself.
- The app currently depends on a locally available Ollama model for AI analysis.
